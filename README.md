# Metadata processing scripts – Radio France

This repository contains Python scripts developed as part of my fixed-term contract at Radio France.

The main purpose of these scripts is to assist documentalists in processing, cleaning and verifying metadata, in order to facilitate the production of visualisations and analyses related to media pluralism.

The tools offered are designed to:
- improve the quality of descriptive fields (programme titles, contributors, etc.);
- automate certain cleaning operations;
- ensure the reliability of data prior to analysis and visualisation.

##  Installation 
Install localy 
```bash
virtualenv env -p python3
source ./env/bin/activate
pip install -r requirements.txt
```
